# Worklog 2026-08-17

## 12:27 CST — QBE native backend M5 ownership descriptors delivered

- **What:** Completed the remaining M5 item from `08-qbe-native-backend.md`: native signatures now carry ownership descriptors. `NativeRegistry::DeclaredSignature` gained per-parameter `Ownership` (`Copy`/`Borrow`/`Move`) and result ownership; `native fun` parameters default to `Copy` and results to `Move`. The QBE lowering uses those descriptors to deep-copy aggregate arguments before AOT shim calls, matching the VM's per-call `deepCopy` semantics.
- **Why:** The AOT shim layer previously passed Tier 0 string/array pointers straight to C, which could let a native observe or mutate the caller's value. Ownership descriptors are the declared-ABI step that makes copy-first semantics explicit and enforceable.
- **Files:** `include/native.hpp`, `include/native/lowering.hpp`, `src/driver.cpp`, `src/native/lowering.cpp`, `test/native_function_test.cpp`, `test/native_qbe_test.cpp`, `docs/design/rearchitecture/08-qbe-native-backend.md`.
- **Verification:** Full ctest 559/559 green, including the native differential sweep.

## 13:07 CST — ngi --native --output writes a standalone binary

- **What:** Added `--output <path>` / `-o <path>` to the native driver. With `--native --output`, `ngi` compiles QBE IL, assembles, links to the requested path, and prints `native executable written to <path>` instead of running the program.
- **Why:** `ngi --native` previously compiled to a temp directory and ran immediately, so users could not easily keep a compiled binary.
- **Files:** `src/driver.cpp`, `test/driver_test.cpp`, `test/native_qbe_test.cpp`, `docs/design/rearchitecture/08-qbe-native-backend.md`, `.agents/workstate.md`.
- **Verification:** Manual `ngi --native --output /tmp/ng_hello --source ...` produces a runnable binary; relevant driver/QBE tests pass.
