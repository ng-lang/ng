# 2026-09-14

## INC-20b — `Box.clone()` real deep copy (INC-20 unblocker, option (a))

Implemented, verified, docs-synced; commit pending as a `feat(vnext)` +
`docs(vnext)` pair.

**What changed:**
- `Box.clone()` now deep-copies into a fresh cell. Typechecker records the call
  via `boxCloneCalls` when the receiver is a `Box` (`isBoxReceiver`); FlowIR
  emits `BoxClone` for Box receivers (vs `LoadRef` for other derived clones).
- `emitClone` top-level Box copies → `emitBoxEnvelopeCopy`: `$ngrt_alloc(8)`
  fresh heap envelope + copy of the handle word. Fixes the "invalid heap
  handle" regressions (q2, box.ng double-drop variability): `new()`'s box
  literal lowered to a *stack* envelope (QBE `alloc8 8` = alloca); a prior
  shallow shortcut returned a dangling stack pointer that the drop later read
  as a stale/non-cell handle. Envelopes share the cell (drop-exactly-once;
  box is affine so no double-release), are arena-owned and never released.
- Enum deep clones route through `$ng_clone{id}_helper` from user bodies
  (`cloneHelperStream_` gate); the inline tag ladder is emitted only inside the
  helper. Fixes `list_spread.ng` `qbe: predecessors not matched in phi %t279`:
  an inline ladder's unterminated last block fell through to the next
  structured block label.
- Composite payloads (struct/tuple/enum with Box fields) texture-deep-copy
  through `emitCloneDeep` so a cell never aliases payload memory.
- `example/box.ng` + INC-20B clone section (write-isolation + `outstanding()`
  balance, return bits 128/2048/4096/8192); box_test +3 `[Box][INC20]` cases;
  plan INC-20 entry annotated with the INC-20b outcome and INC-20c next step.

**Why:** the INC-20 blocker (2026-09-11 probe) was that `Box<T>` handle words
are shallow-copied by `read`/`load` and `hasDrop` does not recursively drop
Box fields — so `std.list` over Box nodes needs a deep-copy primitive. This
lands option (a): Box `clone`.

**Verification:** `example/box.ng` exit 0; clone probes p13 (recursive
`Box<E>`) / p14 (leaf) / clone_rec2 (deep enum walk) exit 0; `list_spread.ng`
exit 0; full ng_test **623/623 (3758 assertions)**; ASan probe batch clean;
guard floor maintained (flowir.cpp back to 2256, at ceiling).

**Remaining:** INC-20c — migrate `lib/std/list.ng` onto Box nodes and remove
