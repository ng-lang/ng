## INC-B · core traits declared in prelude.ng (committed `c1e733b` + docs `4040ecd`)

- **What:** Moved the core traits out of compiler injection: `Copy`/`Clone`/`Eq` are now
  `export trait …` in `lib/std/prelude.ng`; `registerTraits()` no longer injects them; the
  derive validator queries registered traits; `clone` accepted as a trait method name
  (`TokenKind::KeywordClone`); derive tests and `example/derive.ng` gained `import prelude;`.
- **Why:** INC-8/INC-B flow — traits belonged in source (stdlib), not compiler injection;
  explicit imports keep the typechecker's visibility-blind overload registration sound.
- **Verification:** 488/488 cases (2329 assertions); ctest 489/489 incl. example corpus;
  ASan green apart from the pre-existing imgui link failure (`driver_test.cpp:178`).

## INC-A · prelude auto-loading — skipped by decision

- **What:** Attempted auto-injecting `import prelude;`; the typechecker registers overloads
  for all merged modules uniformly (visibility only affects resolver name lookup), producing
  ambiguous specializations with local declarations; restricted injection/shadowing variants
  would not converge. **User decision:** explicit `import prelude;`; auto-load deferred until
  the typechecker registers overloads per-module-visibility.

## INC-9 · diagnostics stage one — error codes + did-you-mean (committed `e38e51c` + docs `55b815d`)

- **What:** Added a `code` field to `TypeError`/`ResolutionError`/`ParseError` (defaults
  `E-type`/`E-resolve`/`E-parse`); driver now emits `type error E-xxx at bytes [b, e): msg`.
  Core sites carry specific codes: `E-move-used`, `E-move-field`, `E-move-partial`,
  `E-borrow-conflict`, `E-borrow-too-many`, `E-compare-mixed-sign`, `E-compare-mixed-kind`,
  `E-unresolved-name`, `E-name-not-visible`. The resolver appends `; did you mean `X`?` for
  unknown/not-visible names within Levenshtein ≤2 over module-internal candidates.
  The INC-2 negative-contract runner gained a mandatory `code:` directive; the three
  `.neg.expected` files upgraded; borrow/move/float/driver unit tests assert `error.code`.
- **Why:** INC-9 spec — stable UI test anchors for all later increments; cheapest to build now.
- **Verification:** 489/489 cases (2348 assertions); ctest 490/490 incl. corpus;
  ASan green apart from the same pre-existing imgui link failure.

## INC-10 + DEC-B · while/continue/break (committed + docs)

- **What:** Added `while`/`continue`/`break` end to end. Syntax: new keywords/tokens,
  `WhileStatement`/`ContinueStatement`/`BreakStatement` AST nodes, block-parser dispatch.
  HIR: `StatementKind::While/Continue/Break`; resolver now captures bare `next` only in a
  `loop` WITH binders (DEC-B: a `while` and a binderless `loop ()` never capture `next`, so a
  body-level `next(args)` stays a self-tail-recursion call against the enclosing function);
  `break` targets the nearest loop/while, `continue` is valid only when the nearest
  loop-like construct is a `while`. FlowIR: `lowerWhile` emits a header `Branch` + body
  `Jump` back-edges (fall-through = implicit `continue`), `lowerContinue`/`lowerBreak` lower
  to plain `Jump`s to the loop header/exit, plus a `loopExits_` map; no new terminator kinds.
  Const interpreter: `runWhile` (Fallthrough re-evaluates the condition — a bug where the
  first run returned immediately was fixed) plus `Control::Kind::Continue/Break`.
- **Why:** DEC-B + INC-10 spec — flag-free search loops; tail-recursion rule stays stable.
- **Verification:** desugar-equivalence PBT (300 generated state machines: `while`+`continue`
  form ≡ hand-written `loop`/`next` form, checked equal on const and native paths); three
  negative contracts (`while`-body `next` arity error points at function params,
  `continue` in a `loop` rejected, top-level `break` rejected); flowir/resolver/typecheck/
  parser unit tests; `example/while_loops.ng` (flag removed via `while`/`break`/`continue`).
  Full suite 489→497 cases (3303 assertions); ctest 490→498 all green; ASan same pre-existing
  imgui link failure only. D-010 revision text landed in `04-language-decisions.md`.
