# 2026-09-10

## INC-17 — borrow 捕获闭包 (M2b)

- **Purpose**: M2b slice: an explicit capture of a scoped reference
  (`[r] || { ... }`) makes the closure an anonymous borrower of the referent —
  the INC-16 (D-002 A1.2) NLL corpus replayed as closure-capture variants plus
  the multi-bearer release semantics M2b adds.

- **Multi-bearer loans.** `Loan` now carries `bearers: vector<uint32_t>`
  (`0` = untied expression loan) instead of a single tied local; the loan
  releases at the **last surviving bearer's** last-use statement
  (`releaseLoansUsedUpTo` release-by-use-site). Bearers = the ref binding
  itself + every closure local capturing it. A closure that outlives the ref
  binding still guards the referent; with both closures dead, move/assign is
  allowed again.

- **State restore bug (the breaker).** `checkFunction` never saved/restored
  the enclosing function's transient borrow/move state — the `for`-loop
  clobber that masked several pre-existing bugs. Fixed by save/restore; this
  immediately exposed:
  - `example/hkt.ng`: `let back = ref back;` (borrow-of-borrow) → `ref back`
    on the argument value directly.
  - `example/option_result.ng`: `Option.None` consumed twice (real
    move-after-move) → added `let empty: Option<i64> = Option.None;` and pass
    `empty` to `optOrElse`.
  - **Nested-call double inference** (`typecheck_infer.cpp`): `analyzeCallSpread`
    eagerly fully-infers every non-closure argument, then the call's argument
    loop inferred the same argument again (`argumentTypeAt`) → the second pass
    re-read a by-value affine local the first pass already consumed → spurious
    `E-move-used` on a nested call like `optMap(optMap(one, ...), ...)`. Fixed
    by reusing `spreadInfo.expandedTypes[index]` for non-closure, non-spread
    arguments (closure slots stay `TypeId{}`, inferred on demand).

- **Dead-capture release.** A capturing closure that is never called/read
  releases its loan at its declaration (closures cannot escape their scope,
  INC-14) — `lastUseByBlock.visitStatement` records `lastUse[...] = statement
  index` for `Let` statements whose expression is a `Closure`.

- **Probe caveat (pre-existing, out of scope).** Bare expression statements
  `move s;` are not run through `trackConsumption`
  (`StatementKind::Expression` does only `infer`) — tests use the gated form
  `let y = move s;`.

- **Verification.** `test/borrow_capture_test.cpp` (11 TEST_CASEs, `[INC-17]`):
  INC-16 corpus as closure-capture variants (move/assign of referent while a
  capturing closure lives → `cannot move/assign ... while it is borrowed
  (D-002 A1.2)`), M2b semantics (loan outlives the ref binding; two sharing
  closures release only after both are dead; dead closures release at
  declaration; write-through captured `ref mut` reaches the referent at
  runtime), and `(*write).v := 9` place-through-assign. E2E example
  `example/borrow_capture.ng` (6 assertion prints all true, exit 0). Focused
  suite `[Borrow],[Move],[Origin],[NLL],[Closure],[S3],[S4],[Errors],[Examples],
  [INC-16],[Derive],[INC-17]` → **193 test cases / 801 assertions all
  passed**. (Full-suite count pending final run.)

## INC-16 — 引用入聚合与跨调用借用（D-002 A1.2/3）

- **Purpose**: D-002 A1.2/3 slice: cross-call borrow soundness
  (use-after-move-through-ref), place-through-ref reads/writes behind scoped
  references, and the reference-in-aggregate permission rules.

- **S1 — move/assign/borrow interplay (A1.2).** New checker gates:
  `Checker::isBorrowed` (any live loan exists for a local) + `placeName`
  (place-path rendering) in `src/typecheck_check.cpp`. `trackConsumption`
  now fires `E-borrow-conflict` when a move (Prefix move, affine Member
  consume, affine ResolvedName carry) touches a borrowed local; the `Assign`
  handling fires on borrowed whole-locals and place targets. Loan release is
  statement-grained (last use in a statement / statement end / scope exit), so
  move/assign after the last use still compiles. Diagnostics follow
  `cannot move `X` while it is borrowed (D-002 A1.2)` /
  `cannot assign to `X` while it is borrowed (D-002 A1.2)` /
  `cannot assign to this local (of type T) while it is borrowed (D-002 A1.2)`.

- **S2 — place-through-ref (A1.2).** Four pieces:
  1. `src/hir.cpp` — a `T ref mut` parameter is a mutable sub-target root
     (`items[i] := ...` / `b.value := ...` resolve without an explicit `*`);
     the resolver detects a top-level `ScopedReferenceTypeSyntax.isMutable`.
  2. `src/typecheck_infer.cpp` — Index/Member unwrap `Reference` receivers;
     ref-through-ref creation (`ref r[0]`) and slicing (`r[a..b]`) rejected as
     deferred A1.3; assigning through an immutable `ref` rejected
     (`cannot assign through an immutable reference`); reassigning a scoped
     reference binding rejected.
  3. `src/flowir.cpp` — `lowerPlace` roots a Reference-typed local as a ref
     root (`LoweredPlace{.rootRef = ...}`); the Member place path resolves the
     field ordinal against the *referenced* descriptor; expression-level
     Index/Member reads on a reference receiver deref first via `LoadRef`
     (deep-copy value semantics preserved).
  4. `src/type_interner.cpp` — Reference fields rejected at both struct
     instance build sites.

- **S3 — aggregate permission rules (D-002 rule 8).** Struct fields cannot
  hold a scoped reference (`references cannot be stored in struct fields`);
  enum payload references remain the sanctioned exception (recursive
  `List<T>` in `lib/std/list.ng`); module consts are compile-time bool/i64
  only so no runtime global can hold a reference (vacuously enforced).

- **Found while probing (pre-existing, NOT INC-16 regressions):** mixed
  cross-function ref reads returned "garbage" values that turned out to be
  **exit-status truncation** (main return >255 → process status low 8 bits);
  the underlying reads/writes were correct. Both a pre-S2 baseline stash
  check and value prints confirmed the reads were right.

- **Verification.** New contract corpora: `test/nll_problem_cases_test.cpp`
  (classic NLL case families 1–4 as negative contracts + release-after-last-use
  positives + E2E), `test/place_through_ref_test.cpp` (S2 positives +
  negatives + E2E), `test/ref_permissions_test.cpp` (S3 rules). Example
  `example/place_through_ref.ng` runs end to end (8 true assertions + main
  returns 42). Full suite **598 test cases / 3694 assertions all passed**,
  `ctest --test-dir build -j` **599/599**. Guard `flowir.cpp` 2203 → 2256
  (justified in `test/guard_test.cpp`).

- **Deferred (A1.3) boundary, carried to INC-17/M2b:** reference-through-
  reference creation and slicing through a scoped reference; closure capture
  variants of this corpus.
