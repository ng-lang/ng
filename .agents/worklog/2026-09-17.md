## INC-21 S1 — span\<T\> borrowed scoped view over array storage

Post-cutover A7 (span views over array storage, bounds-checked slicing).
User-confirmed split: **S1 = span\<T\>** (this entry), **S2 = array growth /
in-place pushBack + growth PBT** (pending). Resolved a plan-labeling mismatch in
passing: INC-21's own text ("span\<T\> + 数组增长 + in-place pushBack") is
authoritative over the post-cutover plan's A7→INC-24 mapping (INC-24 is the
growth-only follow-up; both derive from the same A7 slice).

**Surface (as delivered):** `span xs` (whole array view), `span xs[lo..hi]`
(bounds-checked window), element reads `view[i]` bounds-checked. Runtime value
is a 16-byte arena blob `{data, len}` (MakeTraitView 24-byte precedent);
`$ngrt_span_make(l array, l start, l count)` and `$ngrt_span_get(l blob, l i)`
in `src/native/helpers/span.ssa`, both halting on out-of-range (negative
contract — tests assert exit 1 + "killed by a signal"). Types `span<T>` / `T
span` → `TypeKind::Span` (interner, unify, const, display all mirrored from
Reference).

**Borrow model:** the `span` expression registers a **shared** loan on the
source root via the exact `ref` prefix machinery (`borrowExpressions_` +
`borrowState_.counts`), so a live mutable borrow of the source conflicts
(E-borrow-conflict), and a later `ref mut` conflicts while the span is still
live. Loan liveness is NLL via `lastUseByBlock`; the `let v = span xs` handler
re-ties the untied bearer-0 loan to `v` exactly like the ref binding handler
(`typecheck_check.cpp` ~439). Writes, returns, struct-field/array/tuple
stowage, span-of-span slices, and span rebinding are all rejected at typecheck.

**Lowering path:** `InstructionKind::MakeSpan` (flowir; window operands `{start,
end}`, whole view = empty operands) → `MakeSpan` case in
`lowering_expr.cpp` (root forced into a heap cell in pass 1a like MakeRef
roots — the early draft omitted this and crashed `unordered_map::at` on
SSA-only locals) → `$ngrt_span_make`; span element reads dispatch to
`$ngrt_span_get` by receiver type at `ExpressionKind::Index`. qtypeOf(Span) →
Long. Guards bumped: flowir **2262 → 2302**, ast.hpp **980 → 991** (both with
INC-21 comments).

string arrays, OOB window + OOB read negative contracts, borrow conflicts both
