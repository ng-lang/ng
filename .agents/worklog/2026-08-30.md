## INC-11 · derive(Show) — implemented, verified, pending commits

- **What:** Added `derive(Show)` end to end. `lib/std/prelude.ng` now declares
  `export trait Show { fun show(self: Self ref) -> string; }` (sibling of Copy/Clone/Eq,
  per D-011). The derive-registration loop gained a `Show` branch that validates each field
  is a `string`, a scalar with a native `toString` overload (prelude i64/i32/u64/f64/bool),
  or a Show-derived nested struct (declaration-order dependent, mirroring derive(Eq)), and
  records the scalar→`toString` native DefId in `showToStringTargets_`. `typecheck_infer.cpp`
  gained a `show` special-case after the `clone` branch (records `derivedShowCalls_`, returns
  `builtin::String`, receiver is `Self ref`). `flowir.cpp` `lowerMethodCall` loads the struct
  value and synthesizes the `name{field: value, ...}` string (research A4 format, no spaces
  inside the braces): string literals + `$ngrt_str_concat` chains (`+` payload 1), per-field
  `ExpressionKind::Member` extraction, native `toString` calls for scalars, and recursion for
  nested derived-Show structs via the new `buildShowString` helper. Hit-path confirmation:
  the driver lowers native functions into flows, so synthesized `toString` instructions
  dispatch through `nativeDefIds` by name + declared type.
- **Why:** INC-11 spec (research I5 slice 2) — mechanical field-level string synthesis at
  the same extension point as derive(Eq); enables files below to rely on a stable textual
  representation of product types.
- **Naming ripple:** because the merged module would now contain two `Show` traits, all
  local `trait Show` declarations in sources that also `import prelude` were renamed to
  `RenderText`: `test/trait_stage1_test.cpp` (5 sites), `test/const_fun_test.cpp` (2 sites),
  and `example/{trait_defaults,generic_impls,generic_const_fun}.ng`. Local `Show` in sources
  that do not import prelude (trait_object/trait_stage1/native_qbe/where_clause snippets) are
  untouched.
