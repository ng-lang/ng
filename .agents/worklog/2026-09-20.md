`.agents/workstate.md` (2026-09-19) under user decisions: **unique-own

**unit-level model**.

**Implementation (all in one S2 commit today):**

- `arr.ssa` helpers `$ngrt_arr_push_mut` / `$ngrt_arr_push_cow`; growth =
  `cap*2 + 4` (≥4) and re-point the slot on realloc. QBE gotchas: `jnz` needs
  **two** labels; cross-block live values need an explicit `phi`.
- Growth analysis `src/typecheck_growth.cpp` (new, wired into
  `typecheck_check.cpp` after `recordFallthroughDrops`): flow-insensitive
  `sharedLocals` escape analysis over array locals + `pushBack` classification.
  Two passes (collect escapes, then stamp) — first draft was order-dependent
  (later `len(xs)` had no effect on earlier pushes). Local types read from
  `localTypeIds_`, NOT the `locals` map that reaches the end of `checkFunction`
  (checkBlock takes it by value; only params survive).
- `TypeCheckResult::inPlaceMutationCalls` (call expr → bool), stamped onto the
  Call payload in `flowir.cpp`, split in `lowering_call.cpp`.
- Guard bump: flowir **2302 → 2310**.
- List: `pushBack(List<T> ref mut, T)` **rebuild-per-push** (see decision
  below); `pushBackCow` retarget + `resolvePushBackCow` removed from the
  checker; `pushTailAppend` removed.

**Decision (user, via question tool on 2026-09-20):** the locked "List too"
in-place plan was **not implementable** — end-to-end probes showed std.memory
Box payloads deep-copy on read/pattern-bind, so walking
`Cons(head, tail: Box<List<T>>)` and writing through `ref rest` mutated a
throwaway copy (runtime assertion + wrong length); `ref`-of-`ref mut` is
rejected (`A1.3`), making the COW branch unreachable; affine moves mean `let b =
a` is an `E-move-used`, so two live List bindings can't even be written. User
picked: **List rebuild-per-push** — `*list := append(ref current, v)` (O(n) per
push, correct value semantics), documented as such; the O(1)-amortized promise
is delivered on the array path.

**Verification:** `[Growth]` suite (4 cases / 172 assertions): model PBT (80
trials, `pbt::currentSeed("growth")` — push-built ≡ one-shot `[...]` element-
wise, unique vs COW halves via an early `let b = xs`), SSA symbol contracts
(`push_mut` unique / `push_cow` aliased), deref write-back `*refMut := e`
round-trip, negative contract (immutable binding reject). `example/growth.ng`
end to end (exit 0, prints 140). Full suite **640/640** green, guards pass.

## INC-22 — M5 Cell\<T\> (handle式内部可变性)

Follows INC-21 S2 (committed `5650d6a`/`c016b85`/`24986d9`). User decision:
**affine owning + Drop** — `Cell<T>` mirrors `Box<T>` (owns the Handle,
`impl Drop` releases drop-exactly-once, affine moves) but `cellGet`/`cellSet`
take a **shared** `ref`, so many co-borrowers may read and write one cell
without a `ref mut`; ref-mut exclusivity still applies whenever a mutable
borrow is actually taken.

**Implementation (pure stdlib, no compiler changes):** `std.memory` adds
`Cell<T>` (Handle field) + generic `Drop` + `newCell<T>` / `cellGet<T>` /
`cellSet<T>` (internal explicit-generic `allocate<T>`/`load<T>`/`store<T>`
calls, same as `new`/`read`/`write`). Every existing Box/Handle/Drop mechanism
was reused unchanged.

**Probe findings:** shared-ref mutation works — `let r = ref c; cellSet(ref c,
9); cellGet(r) == 9`; cross-call mutation through refs works; `ref mut`-live +
`cellSet` → `E-borrow-conflict` (both orderings — interior mutability does not
dodge exclusivity); affine `let d = c` moves. Closure **copy-capture of an
affine Cell double-releases** (invalid heap handle), and capture-ref forwarding
to a `ref` param is A1.3, so the INC-14/17 "closures capturing shared state"
scenario is carried by cross-call shared refs instead — documented.

**Verification:** `[Cell]` 5 cases / 15 assertions — 48-pair get/set round-trip
PBT (`pbt::currentSeed("cell")`, single fixture, `outstanding()` balanced across
the loop), word/string/array/struct payload round-trips, shared-ref observation,
ref-mut exclusivity negative contracts (both orderings), affine move reject.
`example/cell.ng` prints all true. Full suite **645/645**; ASan cell/box/growth
slices clean. Guards unchanged (no C++ edits).
