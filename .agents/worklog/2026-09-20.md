**Decision (user, via question tool on 2026-09-20):** the locked "List too"
in-place plan was **not implementable** — end-to-end probes showed std.memory
Box payloads deep-copy on read/pattern-bind, so walking
`Cons(head, tail: Box<List<T>>)` and writing through `ref rest` mutated a
throwaway copy (runtime assertion + wrong length); `ref`-of-`ref mut` is
rejected (`A1.3`), making the COW branch unreachable; affine moves mean `let b =
a` is an `E-move-used`, so two live List bindings can't even be written. User
picked: **List rebuild-per-push** — `*list := append(ref current, v)` (O(n) per
push, correct value semantics), documented as such; the O(1)-amortized promise
is delivered on the array path.
